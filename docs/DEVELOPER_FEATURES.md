# 功能分级与 Developer-only 集成

本页描述 **2026-11-01 公开源码快照**。开发者专用意味着“仓库提供了适配器/实验实现，但你还需要开发、部署、凭据或硬件”，不代表维护者提供这些服务，不代表所有入口已端到端验证。

**没有维护者服务器地址或公共服务账号，也没有需要向维护者索取的解锁密码。** 请为自己的实例配置所需能力。未配置时显示不可用/未知是正常行为；不要伪造成功、零数据或读取结果。

## 核心与可选配置

| 能力 | 仓库中已有 | 使用者要准备 | 边界 |
|---|---|---|---|
| 聊天与全部历史搜索 | SwiftUI、SQLite、app-server adapter、消息日历/高亮/返回 | 自己的 Codex 账号、工作目录、Cove 后端和 HTTPS | 可用模型/额度由账号决定；消息数不是记忆数 |
| Markdown、文件、表情、widget | 原生渲染、耐久传输、工具回执 | 无额外云服务；路径导出要设 `COVE_EXPORT_ROOTS` | 不执行任意 JS；HTML/SVG 是惰性附件；媒体加载需确认 |
| 健身/个人账本 | 本地记录、预算/分期/更正、可选同步与代记 | 手机本地存储；同步/代记须持续授权 | 不接银行、不支付；与助手虚拟钱包完全分离 |
| 助手钱包 | 独立本地后端账目、每日虚拟额度、购买请求/审批 | 自托管后端，用户主动审批 | 演示/陪伴应用的虚拟账目，非支付账户；收入规则可改源码 |
| APNs | 消息入库后通知 | 自己的 App ID、Team/Key ID、`.p8`、设备注册和推送能力 | 通知不是消息投递唯一来源；权限、Focus、环境都可能影响显示 |
| HealthKit | 真实采样日期/范围、授权、请求卡、共享副本 | HealthKit capability、真实 iPhone/数据、明确授权 | 不诊断、不保证后台实时性；删除副本不删除 Apple Health |
| 日历/提醒/闹钟 | EventKit / AlarmKit、逐动作确认与 ACK | 系统版本、签名能力、用户授权、前台执行 | 不是任意手机遥控；不等于读取所有 Apple Clock 闹钟 |
| App 使用事件 | 独立写入token、原生App Intent本机队列、逐端ACK和日视图 | 用户创建快捷指令触发器并配置写入专用凭据；第二兼容接收端需自备后端 | **不是 Screen Time 全量采集**，不导入旧历史；后台及时性由系统决定 |
| Apple WeatherKit | 官方响应/归属处理与工具 | 自己的 Apple WeatherKit Services ID、Team/Key ID、私钥 | 目前是北京代表点，不读取用户定位；他处天气要改位置与对应测试/归属；不可删官方归属 |
| 家／公司围栏 | 本机选点、系统区域监控、初始状态确认、状态进入已有模型输入 | 独立默认关闭的分享授权；后台监控需要Always/精确位置及设备能力 | 不上传中心坐标/路线，不额外唤醒模型；后台实际进出需自行验收，见 [围栏协议](GEOFENCING.md) |
| 位置与地址 | MapKit 地图卡/搜索选点、Apple 反向地理编码、独立持续授权/请求/回传 | 系统定位权限与联网；自动请求另需明确开启持续授权，后台提醒需 APNs | 只在前台按需取一次，不持续追踪；地点地址可能缺失或近似，历史卡不自动补地址 |
| 录音/播放/付费 TTS | iOS 录音、波形/seek、可选 MiniMax / ElevenLabs adapters | 麦克风权限；TTS 需自己的 key、获授权 voice ID 和额度 | 未附带私人声线/表达配置/录音；调用可能付费，未知结果不自动换供应商重试 |
| 本地换窗 | 持久交接、同对话线程续接、上下文计数 | 协议匹配的 Codex CLI；配置适合模型窗口的阈值 | 当前默认预算针对大上下文模型；不要假设适合所有账号/模型；旧记录不删除 |

## Developer-only：额外服务与实验能力

### Pulse / 主动唤醒

- 公布：`server/pulse_read.py` 的只读状态投影、唤醒接入、公开 note 回执和 App 心跳页面。
- **不公布/不附带**：维护者的 Pulse 状态库、个人动力学配置、heartbeat 生产服务、私人人格提示词。
- 普通聊天不需要 Pulse。只有自行配置 `COVE_PULSE_PATH` 才读取该状态；独立调度器需要遵循 backend 的鉴权与回合规则。
- 自动唤醒会消耗模型额度并可能主动发送消息。必须由用户明确启用、设置频率/时段/成本限制；UI 中的数字身体值不是传感器或医疗数据。

### Ombre / 叙事记忆池

- 公布：只读日历/证据读取适配器、待记清单、精确回执与本地交接。
- **不附带 Ombre 服务、向量库、embedding/compression 账号、维护者的记忆或叙事池构建管线。** 这是独立系统，不是聊天 SQLite 的别名。
- `COVE_OB_BUCKETS_PATH` 指向操作者自己的兼容 bucket 目录；`COVE_OB_NAIVE_TIMEZONE` 明确无时区旧记录的来源。
- `COVE_MEMORY_DB` 只有显式配置才读取外部派生库；`COVE_CHAT_DB` 可覆盖本实例聊天库的路径。默认不探测其他人的记忆目录。
- OB MCP 工具映射由 `COVE_HANDOFF_OB_WRITE_TOOLS` / `COVE_HANDOFF_OB_READ_TOOLS` 等配置；仅在配置自己的服务且用户授权后才写长期记忆。`queued/unknown` 不代表成功，只有真实读回 `confirmed` 才算保存。
- 自动续接的本地聊天记录不要求共享维护者的 OB，也不能继承任何私人身份或授权。

### Collar / Apple Watch

- 公布：Cove 侧请求、只读摘要、回执与桥接服务代码。
- **不附带独立 Collar Watch App、它的 ingest/store 依赖、设备配对、证书或推送 token。** `collar_bridge.py` 需要操作者的兼容 `CollarStore` 实现。
- 自行部署并设置 `COVE_COLLAR_URL` / `COVE_COLLAR_TOKEN`，配置独立 `COLLAR_COVE_*` 环境、自己的 Watch topic 和设备注册。
- 持续被动读取与主动测量是两项权限；Pulse 不能借读取权限发起主动测量。返回 pending 不是已经测量或振动。

### 特定 BLE 硬件

- 公布：iPhone 直接 BLE 连接、有限高层命令、保活、全停/撤权与手机 ACK 的实验适配器。
- 只适配代码明确描述的 SOSEXY / SL278 协议，不是通用设备控制器。你需要自己的兼容硬件、实机测试和明确用户授权。
- 新版通过 CoreBluetooth 恢复用户曾明确选定的设备、提交系统重连并在 HTTP ACK 前恢复保活；只恢复连接，不重放旧动作。系统挂起/强退后的行为仍需硬件验收，不保证任意后台 HTTP 定时器持续运行。
- **源码存在不代表硬件安全认证**。先验证全停、断线、撤权、ACK/超时和后台行为；不得自动连接附近陌生设备，也不能把“写入命令”宣称为设备已执行。

### 旅行 / 相册 / 图片生成

- 公布：Cove 的旅行状态、邀请/用户回应、相册和 loopback bridge。
- **不附带外部旅行引擎、地图数据服务、图片生成工作流或供应商凭据。** `COVE_TRAVEL_TOKEN_FILE` 未配置时保持未启用。
- bridge 默认使用本机 `127.0.0.1:18797`，需要你实现兼容接口；它不是任何可直接使用的公网地址。所需操作看 `server/travel_bridge.py` 的 allowlist。
- 生图可能付费；费用、地理数据、模型授权和来源标识由操作者负责。角色场景不是用户真实位置记录。

### 离线语音理解 / 实时语音

- 公布：原音容器校验、离线 helper、声学近似、WebRTC / app-server realtime 的实验桥接。
- 离线分析需要自行配置 `COVE_VOICE_PYTHON`、`COVE_VOICE_MODEL`、ffmpeg / sherpa-onnx 及合法模型资源；模型权重和个人基线不随仓库发布。
- realtime 取决于所装 Codex 的协议、账号及上游支持。**不保证普通订阅支持，也不是完整电话产品**；不能因为看到通话按钮就宣称能通话。
- 声学近似不是声纹身份识别，不可靠地证明情绪或健康；不能从文字标点假装听见语气。

### 实验 tmux / Shell

- 主线路仍是 **app-server**。tmux 模块是独立实验分支，不是推荐默认运行方式，也不自动降级切换。
- 选择 `COVE_RUNTIME=tmux` 需要专用 Codex 二进制、独立 `CODEX_HOME`、tmux、注册表、原生 hook/rollout 和隔离 socket；必须自己验证，不要接管别的活跃会话。
- app-server 执行日志、受限 Shell 和原生 tmux TUI 是不同能力。审批、输入控制、会话归属和未知结果不得混用。
- 本地原生 CLI 测试默认使用不存在的占位路径并跳过，不会自动扫描或运行维护者/你的真实会话。启用前阅读测试本身，使用隔离账号/目录；本次公开发布没有执行真实模型回合。

## 发布物明确排除

- `.env`、token/key、Codex 登录、APNs/WeatherKit 私钥、签名 profile/证书、个人 voice ID。
- 聊天、健康、使用记录、钱包/账本、叙事/向量库、真实截屏、录音/照片、runtime 日志。
- 私人人格/亲密偏好/长期记忆、设备标识、VPS IP/域名/SSH 配置、运维交接与备份。
- 私有 Git 历史、`docs/private/`、TestFlight 导出、维护者部署脚本。

**不要用其他人的凭据/数据填这些缺项。** 项目级开源许可未指定；第三方依赖许可不等于整个项目的使用授权。
